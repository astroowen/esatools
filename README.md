# esatools
Miscellaneous python scripts for my work at [ESA/Hubble](https://esahubble.org/)

## usage

The recommended way to run this is with the help of `uv`:
- Download uv
- cd to this directory
- `uv run deg2ha.py` or other script
This will install the dependencies for you, put them in a virtual environment, and run the script with them.

Alternatively, just check `pyproject.toml` for the dependencies and make a virtual environment yourself.
